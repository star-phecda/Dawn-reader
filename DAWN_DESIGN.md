# Dawn 0.2.0 — Full visual direction

Dawn is now centered on a deep-night palette with cyan, electric blue, violet and magenta accents. Material 3 Expressive is enabled through MaterialExpressiveTheme and an expressive motion scheme.

## Performance rules
- No continuous animation on ordinary library badges.
- Loading placeholders are static instead of infinite shimmer.
- Novel cards avoid per-item scaling/elevation animation.
- Cover backgrounds avoid large blur passes.
- Decorative atmosphere uses static gradients only.

## Branding
- App name: Dawn
- New launcher/splash artwork is based on the supplied blue-haired character artwork.
- Visible Novery logo artwork has been removed.
- Original applicationId remains `com.emptycastle.novery` for data/install continuity.

## Visual language
Floating capsule navigation, large expressive shapes, cover-led layouts, neon-accent gradients, serif display typography, and restrained motion.
