# Dawn 0.1.0 — redesign pass

- Rebranded the app shell from Novery to Dawn while retaining the existing package/application id for data continuity.
- Added a floating, animated navigation capsule.
- Reworked global colors and typography around a sunrise/ink visual system.
- Added the Dawn mascot launcher/splash artwork.
- Refreshed the Library header hierarchy and search presentation.
- Added short horizontal chapter-edge gestures using the existing previous/next reader navigation.
- Disabled the original project's automatic startup update polling until Dawn has its own release endpoint.
