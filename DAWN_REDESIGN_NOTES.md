# Dawn 0.3 — Full visual overhaul

This source tree is a complete project snapshot based on the Dawn fork, with the
visual overhaul applied across the main reading surfaces:

- deep navy / electric cyan / blue / violet / magenta visual system
- expressive floating navigation capsule
- editorial-style Library, Browse and For You treatments
- stronger History and More surfaces
- grouped, dimensional Settings cards
- cover-led novel details retained and refined through the existing Dawn components
- immersive reader keeps normal scrolling intact and uses an explicit upward pull at
  the end of a chapter for manual next-chapter navigation
- existing Novery functionality, GPL-3.0 license and fork attribution remain intact

This file is a design changelog, not a replacement for the upstream license.
